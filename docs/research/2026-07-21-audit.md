# Technical feasibility audit — 2026-07-21

Primary sources confirm both target testnets are LayerZero V2 deployments: Ethereum Sepolia chain/EID 11155111/40161 and Arbitrum Sepolia 421614/40231. Both official deployment pages list Endpoint V2 `0x6EDCE65403992e310A62460808c4b910D972f10f`. The current DVN interface assigns ULN302 jobs with destination EID, packet header, payload hash, confirmations and sender; the reference DVN verifies quorum-signed calls and tracks used hashes.

The official Gasolina API independently looks up `PacketSent`, enforces confirmations, and offers an extra-context boolean. It does not document pending or retry-after semantics. GenLayer documents the activation → proposal → commit → reveal → finalization pipeline, and warns that accepted results can change during appeal; external messages can execute only on finalized state. This supported the architecture; the exact programmatic finality-consumption API was unresolved in this initial audit and is resolved at the documentation level by the 2026-07-22 follow-up.

Dependencies are intentionally minimal in M0. Solidity imports are local interfaces/implementations so source review is possible; production compilation against pinned official LayerZero/OApp packages is M1 after compatibility validation. No chain or cloud resource was created.

Sources: LayerZero deployment pages, DVN technical reference, Gasolina API reference, production DVN configuration guidance, LayerZero-v2 repository; GenLayer network configuration, messages, non-determinism, and Optimistic Democracy documentation.
