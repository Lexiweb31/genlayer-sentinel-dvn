# Security verification status — 2026-07-22

`npm run check` compiles five Solidity sources with solc 0.8.30 (Shanghai target), strictly type-checks TypeScript, syntax-checks the Intelligent Contract safety boundary, and runs seventy-nine tests. Coverage includes the previous packet, policy, signer, adapter, OApp, listener and API invariants plus immutable bigint-safe destination payload persistence, conflicting preparation rejection, monotonic outbox transitions, intent-before-broadcast ordering, ambiguous-attempt no-rebroadcast behavior, independent two-provider receipt/block/event/used-state verification, pending confirmation depth, confirmed coordinator execution, sanitized delivery API output, canonical signer protocols, durable signer replay protection, durable GenLayer request restoration, bounded ingestion quarantine and safe packet requeue.

Not covered: a standalone daemon or approved account provider, real EndpointV2/ULN302 receive-library calls, live-chain receipt/reorg polling, destination nonce/fee replacement management, authenticated ambiguous-attempt recovery, distributed exactly-once delivery, retry backoff, live GenLayer Studio/testnet compatibility, validator variance and web-render stability, multi-node coordinator storage, production mutual TLS/certificate lifecycle, key custody, five independent signer failure domains, rate limiting, fuzzing, Solidity static analysis, formal verification or third-party audit. `MockEndpointV2` matches the OApp-facing ABI and official packet encoding needed by these tests but is not a security model of the LayerZero endpoint. The Intelligent Contract checker is syntax/guardrail validation, not GenVM execution.

The 2026-07-22 registry audit reports **zero production advisories** from `npm audit --omit=dev`, but the complete development tree reports 22 advisory nodes: 12 low, 3 moderate, 6 high and 1 critical. They are inherited through archived Ganache, the local `solc` compiler wrapper and LayerZero's development-only ethers 5 dependency. These tools are not shipped in the coordinator runtime, but that distinction does not waive the findings. Ganache must be replaced or strongly isolated before public CI handles untrusted artifacts, compiler input must remain limited to reviewed repository sources, and audits must be rerun whenever the lock changes.

`npm ls --omit=dev --depth=2` currently exits nonzero for a separate integrity issue: `genlayer-js@1.1.8` publishes `eslint-plugin-import` as a production dependency, while that plugin declares an unmet `eslint` peer. No production advisory is currently attached to this tree and Sentinel does not invoke the lint plugin, but the runtime install is not dependency-clean. Adding an unused linter would mask the upstream packaging problem rather than remove the unnecessary production dependency. The project will keep the exact lock, track the issue, and evaluate an upstream package correction or a smaller audited GenLayer transport before deployment.

Do not run `npm audit fix` blindly. The registry currently suggests semantically unsafe downgrades such as Ganache 6.4.5 and solc 0.5.0. The complete evidence and upgrade gates are in [`research/2026-07-22-dependency-audit.md`](research/2026-07-22-dependency-audit.md).
