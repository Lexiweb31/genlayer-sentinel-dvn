# Security verification status — 2026-07-22

`npm run check` compiles five Solidity sources with solc 0.8.30 (Shanghai target), strictly type-checks TypeScript, syntax-checks the Intelligent Contract safety boundary, and runs eighty-six tests. Coverage includes the previous packet, policy, signer, adapter, OApp, listener and API invariants plus the isolated Hardhat EDR lifecycle, exact GenLayer JSON-RPC request/response correlation, every documented consensus status pair, rejection of contradictory or malformed status data, the strict `FINALIZED`/`7` gate, successful-execution enforcement, `latest-final` record binding, immutable bigint-safe destination payload persistence, conflicting preparation rejection, monotonic outbox transitions, intent-before-broadcast ordering, ambiguous-attempt no-rebroadcast behavior, independent two-provider receipt/block/event/used-state verification, pending confirmation depth, confirmed coordinator execution, sanitized delivery API output, canonical signer protocols, durable signer replay protection, durable GenLayer request restoration, bounded ingestion quarantine and safe packet requeue.

Not covered: a standalone daemon or approved account provider, real EndpointV2/ULN302 receive-library calls, live-chain receipt/reorg polling, destination nonce/fee replacement management, authenticated ambiguous-attempt recovery, distributed exactly-once delivery, retry backoff, live GenLayer Studio/testnet compatibility, validator variance and web-render stability, multi-node coordinator storage, production mutual TLS/certificate lifecycle, key custody, five independent signer failure domains, rate limiting, fuzzing, Solidity static analysis, formal verification or third-party audit. `MockEndpointV2` matches the OApp-facing ABI and official packet encoding needed by these tests but is not a security model of the LayerZero endpoint. The Intelligent Contract checker is syntax/guardrail validation, not GenVM execution.

The 2026-07-22 registry audit reports **zero production advisories** across the ten-node production tree from `npm audit --omit=dev`. The complete development tree reports 19 advisory nodes: 13 low, 2 moderate, 4 high and 0 critical. Archived Ganache and its bundled native fallback tree are gone. Remaining paths are Hardhat `3.10.0` through `adm-zip`, the local `solc` wrapper through `tmp`, and LayerZero's development-only ethers 5 tree through packages including `elliptic` and `ws`. These tools are not shipped in the coordinator runtime, but that distinction does not waive the findings. Hardhat is restricted to reviewed local test artifacts and a loopback EDR server; compiler input remains limited to reviewed repository sources, and audits must be rerun whenever the lock changes.

`npm ls --omit=dev --depth=2` exits zero and contains only Sentinel's pinned ethers 6 runtime tree. GenLayerJS was removed because production source used it only for enums; Sentinel now owns the small read-only status protocol and keeps account-aware submission/contract reads behind an injected interface. Hardhat is an exact development dependency and is not production-reachable. The version `0.21.0` lock is normalized with pinned npm 10.9.2. Recompiled artifact SHA-256 hashes match `main` for all five contracts, and `contracts/src` has no branch diff.

Do not run `npm audit fix` blindly. The registry currently suggests semantically unsafe downgrades such as Hardhat 0.0.7 and solc 0.5.0. The complete evidence and upgrade gates are in [`research/2026-07-22-dependency-audit.md`](research/2026-07-22-dependency-audit.md).
