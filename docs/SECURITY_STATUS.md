# Security verification status — 2026-07-21

`npm run check` compiles five Solidity sources with solc 0.8.30 (Shanghai target), strictly type-checks TypeScript, syntax-checks the Intelligent Contract safety boundary, and runs thirty-eight tests. Coverage includes the previous packet, policy, signer, adapter, OApp, listener and API invariants plus transactional snapshot persistence, bigint recovery, request-ID idempotency across restart, finalized-state restoration, ambiguous-submit fail-stop behavior, corrupt/mismatched record rejection, durable pending-packet redelivery, acknowledgement ordering, persisted reorg rewinds, strict pathway/DVN-role checks, treasury action decoding, exact evidence hashing, evidence-origin URL rejection, redacted fail-closed runtime manifest parsing, defense-in-depth RPC origin/transport validation and allowlisted same-origin dashboard asset serving.

Not covered: real EndpointV2/ULN302 receive-library calls, live-chain reorg polling, distributed exactly-once delivery, dead-letter/reconciliation tooling, live GenLayer Studio/testnet compatibility, validator variance and web-render stability, multi-node coordinator storage, authenticated signer transport, key custody, five failure domains, fuzzing, Solidity static analysis, formal verification or third-party audit. `MockEndpointV2` matches the OApp-facing ABI and official packet encoding needed by these tests but is not a security model of the LayerZero endpoint. The Intelligent Contract checker is syntax/guardrail validation, not GenVM execution.

The installed development tree reports advisories inherited primarily through Ganache and LayerZero build-time tooling. These packages are not runtime coordinator dependencies; `npm ls --omit=dev` contains only ethers 6.17.0 and its runtime tree. This distinction does not waive the findings: replace or isolate affected test tooling before CI handles untrusted artifacts, and rerun audits whenever locks change.
